## 0. 背景与目标

- 想做外贸:国内很多产品在国外很畅销。
- 当前诉求:先了解**外贸要"跑通"需要哪些环节**,以及**有没有更便捷的通路**。
- 初步框架(用户提出):商品选项(先放,后讨论)、货运 + 支付 + 法规 + 平台。

---

## 1. 全局:外贸的几种"通路"

选哪条通路,直接决定物流、支付、合规上你要自己扛多少。难度从高到低:

| 通路 | 典型平台 / 形式 | 你要自己做的 | 适合谁 |
|---|---|---|---|
| **传统 B2B 外贸** | Alibaba.com、Made-in-China、展会 | 找客户、报关、收汇、退税、大货物流全自理 | 有工厂/供应链、走大单 |
| **跨境电商自运营(B2C)** | Amazon、eBay、独立站(Shopify) | 选品、listing、广告、海外仓/FBA、收款、合规全自理 | 想做品牌、能投入运营精力 |
| **半托管** | Temu 半托管、TikTok Shop | 你备货到国内仓/海外仓,平台管流量 + 末端配送 | 有货、想省运营 |
| **全托管(最省心)** | Temu 全托管、SHEIN 代运营 | **只管供货和定价**,平台包揽运营/物流/售后/收款 | 新手、工厂、想快速验证 |

> **核心结论**:"更便捷的通路" = 全托管 / 半托管。它把货运、支付、合规、平台四件事大部分外包给平台,你几乎只需专注"商品"。代价是利润率、数据主权和议价权较低。

## 2. 逐模块拆解

### 2.1 商品(先放,后讨论)
- 原则:**选品决定约 80% 的成败**,且与通路强耦合(带电/液体/刀具/食品/药妆在不同平台和目的国限制差异极大)。
- 后续单独深聊:数据选品、供应链验证、利润测算、侵权排查。

### 2.2 货运 / 物流
自营模式最容易踩坑、最占资金。分三段:
- **头程(国内→海外)**:海运(便宜慢)/ 空运(贵快)/ 专线(平衡)/ 国际快递 DHL·UPS(小件快贵)。
- **仓储模式**:
  - 平台仓 / FBA(Amazon):省心,但有仓储费、易滞销。
  - 海外仓(第三方 3PL):适合独立站/多平台,时效好、可退换。
  - 国内直邮 / 集运:全托管常用,只发到国内集货仓。
- **末端配送**:目的国本地快递(USPS、FedEx、当地邮政)。
- **关注指标**:时效、丢包率、退货逆向物流、旺季爆仓、体积重计费。

### 2.3 支付 / 收款
分"收钱"和"合规回款"两层:
- **收款(海外买家付钱)**:
  - 平台代收:平台先收再按周期结算(全托管几乎零门槛)。
  - 独立站:接 Stripe / PayPal / 本地卡组织 + 钱包。
- **回款到国内**:第三方收款账户 Payoneer、PingPong、连连、Airwallex、WorldFirst(多币种账户、提现、结汇)。
- **绕不开**:结汇、外汇合规、**出口退税**(需报关单 + 增值税专用发票,显著影响利润)。
- **风控**:拒付(chargeback)、汇率波动、平台冻结资金。

### 2.4 法规 / 合规
最易被忽视但一出事致命。分两端:
- **中国出口端**:出口报关、HS 编码、出口退税、部分品类出口许可。
- **目的国准入端(按品类和国家)**:
  - 产品认证:欧盟 CE、美国 FCC/UL/FDA、能效、化妆品/食品/儿童用品/电池专门法规。
  - 税务:欧盟/英国 **VAT**、美国**销售税(sales tax)**、进口关税与清关。
  - 知识产权:商标/专利/版权侵权是封店头号原因,上架前必须查。
  - 标签/包装/说明书:语言、警示、成分、认证标识。
- **平台规则**:各平台自身合规、类目准入、资质上传。

> 便捷点:全托管下,VAT、清关、部分合规通常由平台承担或指导——这是其"便捷"的核心价值之一。

### 2.5 平台
平台 = 流量 + 交易 + 规则的载体。选择维度:
- **客群**:B2B(批发)vs B2C(零售)。
- **地区**:北美(Amazon/Temu/TikTok)、欧洲(Amazon EU/Otto/Kaufland)、东南亚(Shopee/Lazada)、拉美(Mercado Libre)、中东(Noon)。
- **模式**:平台店铺 vs 独立站(自由度高但要自己买流量)。
- **成本结构**:佣金、月租、广告、履约费。

## 3. 最小可跑通(MVP)路径建议

先跑通、再放大的低风险路线:
1. **定通路**:新手/快速验证 → 先上全托管(Temu / TikTok)或 B2B 挂 Alibaba.com,省掉物流、收款、合规大头。
2. **选 1–3 个品**:无认证/无侵权风险、体积小、非敏感货先试。
3. **供货 + 定价**:全托管下只报供货价,平台定终端价。
4. **打通收款**:开 Payoneer/PingPong 账户,走通回款和退税流程。
5. **验证数据**:看动销、退货率、利润;跑通后再升级到半托管 / 自营 + 海外仓 + 独立站做品牌。

## 4. 如果做成软件工具(可选方向)

围绕外贸可落地的软件模块设想:
- **选品 / 利润测算工具**:输入成本、头程、佣金、退货率 → 算落地利润。
- **合规检查清单**:按品类 + 目的国生成认证/税务/侵权待办。
- **多平台 / 物流 / 收款对比与决策器**。
- **订单 / 库存 / 回款管理面板**。
