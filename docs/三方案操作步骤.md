# A1 / B1 / C 三方案的具体操作步骤 —— 讨论记录

> 记录日期:2026-07-14
> 关联文档:`docs/agent通路与成本对比.md`(方案定义与总价)
> 用途:把三种落地方式拆成可执行步骤,供选型与执行参考

**共同前提(三种方式都需要):**
- 一个销售平台卖家账号(如 Amazon 卖家中心)
- 一个收款账户(Payoneer / PingPong,多币种,绑定进平台)

---

## A1 · 组合工具(最小起步)

思路:自己当"总指挥",用工具分别干选品/文案/执行。

1. 开卖家账号:注册 Amazon 卖家中心(个人/专业版),备齐营业执照、信用卡、地址。
2. 开收款账户:注册 Payoneer/PingPong,拿到美元/欧元账户,绑定进 Amazon。
3. 订阅 Jungle Scout Starter($29/mo 年付):
   - Product Database 按品类/价格/体积/评分筛候选;
   - Opportunity Finder 找"高需求低竞争";
   - Sales Estimator 估月销;Supplier Database 找供应商。
4. 选品定案:导出 3–5 候选 → 利润测算(成本+头程+佣金+退货) → 商标/专利侵权排查 → 定 1 个先试。
5. 供应商询价/打样:1688/Alibaba 询价、打样、验货、下单。
6. Helium 10 免费档:Cerebro/Magnet 查关键词(有额度),Listing Builder 生成标题/五点/描述(复杂功能需 Platinum)。
7. 头程物流:找货代,发 FBA(后台建 shipment 入库计划)或海外仓。
8. 上架:Amazon 后台创建 listing,填入文案 + 产品图。
9. 接入 Jarvio(免费 500 credits → Starter $49):OAuth 连 Amazon,建工作流(每日销量汇报、库存预警、竞品监控、PPC 调价)。
10. 开广告:建 PPC 活动,Jarvio 盯 ACoS 自动调价。
11. 运营循环:Jarvio 每天自动跑,人工做关键决策(补货、调价、回款)。

特点:最灵活、最省订阅费;但串联与决策靠自己,学习曲线陡。

## B1 · 一站式 Accio Work

思路:大部分环节交给平台多个 Agent,你只做关键审批。

1. 注册并订阅 Accio Work(~$99/mo)。
2. 连接账号:OAuth 授权电商平台后台 + Alibaba 采购账号。
3. Sourcing Agent 选品/找货:自然语言描述需求(品类、价格区间、MOQ、认证、物流偏好)→ 返回排序供应商列表(带 Alibaba 报价)。
4. Compliance Agent 合规检查:选定品 + 目标市场(美/欧/英/澳)→ 核对认证/标签/受限材料 → 输出待办(法规更新可能滞后 2–4 周)。
5. 谈判/下单:Agent 辅助沟通、下采购单。
6. 生成 listing + 营销内容:Agent 产出文案/图片 → 发布到平台。
7. 托管运营:库存/订单/竞品由 Agent 监控,关键决策(下单、调价、回款)由你审批。
8. 收款:仍走 Payoneer/PingPong。

特点:上手快、省心;代价是绑定其生态、依赖 Alibaba 供应链,合规更新有延迟。

## C · 自建(选品 + 合规 + 利润测算 最小闭环)

思路:买现成的数据,把有差异化的决策 Agent 自己做。目标:输入品类 → 输出"能不能做 + 落地利润 + 合规待办"。

1. 技术选型:编排 LangGraph/CrewAI;LLM 选 DeepSeek V4 Flash(最省)或 Gemini 2.5 Flash;Python;必要时加向量库。
2. 初始化项目:本仓库目前为空,需先建 Python 工程(pyproject.toml/依赖、目录结构、.env 管密钥)。
3. 定义共享状态:"产品档案 + 目标市场 + SOP"数据结构,供各 Agent 读写。
4. 接数据源:
   - 选品/竞品:Jungle Scout API 或第三方数据(自建也绕不开数据订阅);
   - 合规:CE/FCC/FDA/VAT/退税规则整理成知识库(RAG);
   - 费率:头程/佣金/汇率/退税率表。
5. 实现 3 个 Agent:
   - 选品 Agent:品类/预算/市场 → 拉数据 → 候选品 + 竞品报告;
   - 合规 Agent:候选品 + 目的国 → 检索规则库 → 红黄绿灯 + 待办;
   - 利润测算 Agent:成本/头程/佣金/退货率/退税 → 落地利润 + 建议售价。
6. Orchestrator 编排:三者串成流水线,在"选品定案/资金"节点加 human-in-the-loop 审批。
7. 加护栏:合规判定、利润红线用确定性规则兜底。
8. 测试验证:用真实品类跑几轮,人工核对准确性,监控 token 消耗。
9. 部署:服务器 + 定时任务;记录每轮 token/成本。
10. 迭代扩展:闭环稳定后再加 Listing/物流/客服 Agent。

特点:token 成本极低、可沉淀自有数据与出口合规/退税能力;代价是需开发与持续维护。
