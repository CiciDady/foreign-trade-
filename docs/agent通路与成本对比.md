## 2. 自建 vs 买现成:token 与费用

**结论:纯 token(LLM 调用)成本自建明显更低;但总成本(TCO)在小规模时通常买现成更划算。**

### 2.1 自建 token 成本估算(2026 现价)

一次"选品+合规+利润测算"多 Agent 跑一轮,估算约 10 万 input + 3 万 output token:

| 选用模型 | 单价(输入/输出 每百万) | 单轮成本(估) | 说明 |
|---|---|---|---|
| DeepSeek V4 Flash | $0.14 / $0.28 | ≈ $0.02/轮 | 最省 |
| Gemini 2.5 Flash | $0.30 / $2.50 | ≈ $0.10/轮 | 平衡 |
| GPT-5.4 mini | $0.75 / $4.50 | ≈ $0.21/轮 | 偏 OpenAI |
| GPT-5.4 / Claude Sonnet | $2.50 / $15 | ≈ $0.70/轮 | 旗舰 |

> 每天几十轮,月 token 也就几美元到几十美元;便宜模型 + prompt 缓存可再省约 90%。

### 2.2 三笔隐性成本(自建要自己扛)

- 数据源仍要花钱:选品/竞品数据自建也绕不开(买 API/订阅或自己爬,爬虫维护成本高、易封)。数据才是大头,不是 token。
- 开发 + 运维:LangGraph/CrewAI 编排、对接平台 API、错误处理、监控。
- 基础设施:服务器/向量库/队列,约 $20–50/mo 起。

### 2.3 小规模月成本横向对比(粗算)

| 方案 | 月成本(小卖家) | 特点 |
|---|---|---|
| 买:组合工具 | Jungle Scout $29 + Helium10 免费/$99 + Jarvio $49 ≈ $80–180/mo | 开箱即用,数据全 |
| 买:一站式 | Accio Work $99 / Livey $39 / clawEC 订阅 ≈ $40–100/mo | 最省心 |
| 自建 | token $10–50 + 数据源 $29+ + 基建 $20–50 ≈ $60–150/mo + 大量开发时间 | token 便宜,但要养系统 |

### 不计入合计的浮动成本(所有方案都有)

- 收款手续费:Payoneer/PingPong 约 0.5–1% × 流水
- 平台佣金 + 广告(PPC):按销售额,通常是最大开支
- Helium 10 Diamond 若用 PPC 托管:另有 2% × 超 $5,000 的广告花费

### 一句话选型

- 验证期最省 → A1(≈$78/mo)或 B2 Livey($39/mo)
- 最省心整包 → B1 Accio Work($99/mo)
- 规模化/要差异化 → C 自建($60–130/mo + 开发),出口合规/退税 + 真实利润测算做成专有 Agent 最值

## 3. 成本控制建议

- 先买、后自建:起步用「Jungle Scout(数据)+ Jarvio 免费/Starter(执行)」验证,月成本可压到 $50–80,几乎无开发投入。
- 只自建有差异化、现成做不好的:
  1. 中国出口合规 + 退税 + 结汇 Agent(海外工具空白)
  2. 真实利润测算 Agent(把头程/退税/佣金/退货率算进落地利润)
  - 这两块用 DeepSeek/Gemini Flash 跑,token 成本可忽略,还能沉淀自有数据资产。
- 别自建:选品数据库、多平台上架执行——买现成性价比远高于自爬自维护。

一句话:token 自建便宜到可忽略,但真正成本在"数据源 + 开发运维";小规模买现成更划算,规模化或要差异化时,自建那两个专有 Agent 最值。
