## 1. 市面调研(2026 现状)

行业已从"单点 AI 工具"进化到"多智能体协作运营系统"。亚马逊调研:98% 中国卖家已用 AI,16% 已部署 AI 工作流/智能体做多任务。(来源:21经济网 2026-06)

### 1.1 一站式多 Agent 平台

| 产品 | 归属 / 特点 | 覆盖环节 |
|---|---|---|
| **阿里 Accio Work** | Alibaba,$99/月起 | 选品/供应商筛选、合规监控、供应商谈判、营销;强在对接 1688/Alibaba |
| **实在 Agent(实在智能)** | 国产,TARS 模型 + 视觉识别 | "龙虾矩阵"多机协同(A 选品/B 翻译/C 上架);非侵入式无需 API 直接操作后台;支持 MCP |
| **clawEC** | 国产,"AI 团队" | 定位/调研/选品/利润分析/开店/找货/客服/listing/营销/风控;主打 multi-agent collaboration |
| **Livey AI** | 海外 | Sourcing Agent(扫 1688/Alibaba + 利润分析)、Browser Agent(OAuth 连后台上架/改价/发货)、可自建 pricing/库存/分析 Agent |
| **WarpDriven Autopilot** | 海外 | 6 个专职 Agent,分级自主(辅助→全自动托管),human-in-the-loop 审批 |
| **Jarvio** | 海外 | 原生对话式 AI Agent:PPC/listing/库存/竞品/报表,强调"能执行"非"只给建议" |
| **MeshList** | 海外 | listing 富化:URL 导入 → AI SEO 文案 + 定价 + 多店发布,每 24h 自动选品 |

### 1.2 数据 / 研究底座(很多 Agent 建于其上)

- **Jungle Scout**:选品/机会评分/供应商库/需求预测;2026 版有 AI Agent Workflows 自动竞品基准报告。
- **Helium 10**:关键词/SEO/PPC 自动化(Adtomic 3.0 强化学习自动调价),AI Listing Builder 支持 13 语言。
- **Stormy AI**:骑在上述工具之上的"AI 电商员工",用浏览器拉数据、跟催供应商。

### 1.3 结论

- 成熟环节:选品、listing、上架、调价、客服、竞品监控——现成 Agent 很多。
- 相对空白/可差异化:**中国出口侧的报关 / 退税 / 结汇 + 目的国合规**,海外工具基本不覆盖。

## 2. 多 Agent 协同架构设计

思路:**Orchestrator 协调 Agent + 多个专职 Agent + 共享状态 + 关键节点人工确认**。

```
                        ┌─────────────────────────┐
                        │   Orchestrator 协调 Agent │  ← 拆解/调度/汇总/找人确认
                        └────────────┬────────────┘
        ┌───────────┬───────────┬───┴───────┬───────────┬───────────┐
        ▼           ▼           ▼           ▼           ▼           ▼
   选品Agent    合规Agent    定价/财务   Listing/运营  物流Agent    客服Agent
   (Sourcing)  (Compliance) (Pricing)   (Listing)    (Fulfillment)(Support)
        │           │           │           │           │           │
        └───────────┴──── 共享状态/记忆(产品档案·目标市场·SOP)─────────┘
```

### 2.1 各 Agent 职责

| Agent | 输入 | 产出 | 可对接数据/工具 |
|---|---|---|---|
| 选品 | 品类/预算/目标市场 | 候选品 + 利润测算 + 竞品报告 | Jungle Scout、1688/Alibaba、TikTok 热榜 |
| 合规 | 候选品 + 目的国 | 认证/税务/侵权待办 + 红黄绿灯 | CE/FCC/FDA 规则库、VAT、商标库 |
| 定价/财务 | 成本+头程+佣金+退货率 | 落地利润、建议售价、回款/退税路径 | 收款账户、汇率、退税规则 |
| Listing/运营 | 选定品 | 多语言标题/描述/图片/关键词 | Helium10、翻译 API、平台后台 |
| 物流 | 订单/库存 | 头程方案、仓储选择、时效/成本对比 | 货代 API、海外仓、FBA |
| 客服 | 客户消息 | 多语言自动回复、退换货处理 | 平台消息、知识库 |

### 2.2 协同模式(可组合)

1. **流水线**:选品 → 合规过滤 → 定价 → Listing → 上架 → 物流 → 客服(适合"新品上架"主线)。
2. **协调者-工人**:协调 Agent 按需并行调度(如同时跑合规+定价),再汇总。
3. **事件驱动**:如"竞品降价"触发 → 定价 Agent 重算利润 → 若有毛利 → 运营 Agent 自动调价。

### 2.3 工程要点

- **通信协议**:MCP(Model Context Protocol)对接工具/数据;业界推 UCP 对接店铺/支付。
- **共享记忆**:统一"产品档案 + 目标市场 + SOP"状态库。
- **Human-in-the-loop**:选品定案、定价、上架、发钱等高风险动作需人工确认。
- **护栏**:合规/侵权/资金动作要有确定性规则兜底。

## 3. 自建 vs 买现成

- **不重造数据底座**:选品数据、listing 生成、多平台上架买现成更划算。
- **值得自建/差异化**:
  1. 协调层(Orchestrator):把自有 SOP 编排成流程(LangGraph / CrewAI / n8n)。
  2. 中国出口合规 + 退税 + 结汇 Agent(海外工具空白区)。
  3. 利润测算 Agent:把头程、退税、佣金、退货率算进"真实落地利润"。
- **选型参考(按规模)**:起步 Zapier/Make + Dify;增长期 n8n + CrewAI;规模化 LangGraph 编排全链路。

## 4. 建议的最小闭环 demo

选品 Agent → 合规 Agent → 利润测算 Agent 三个串起来:
输入一个品类 → 输出「能不能做 + 落地利润 + 待办清单」。
